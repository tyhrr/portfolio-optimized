# Alan Salva — Portfolio

Hi, I'm Alan. I'm a web developer and customer support specialist, and this is my personal portfolio website.

The site is a simple front-end project built with HTML, CSS, and JavaScript. It showcases my work, background, and contact details in English, Spanish, and Croatian.

## Run it locally

```bash
git clone https://github.com/tyhrr/portfolio-optimized.git
cd portfolio-optimized
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Files

```text
assets/   Images and documents
css/      Stylesheets
js/       JavaScript
index.html
LICENSE
README.md
```

## Notes

- The language is saved in the browser using local storage.
- Main styling is in `css/styles-optimized.css`.
- Most content and translations live in `js/script.js`.
